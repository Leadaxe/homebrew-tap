# homebrew-tap

Homebrew tap for [singbox-launcher](https://github.com/Leadaxe/singbox-launcher).

```bash
brew install --cask leadaxe/tap/singbox-launcher
```

Update with `brew upgrade --cask singbox-launcher`.

The recommended way to install on macOS is still the [install script](https://github.com/Leadaxe/singbox-launcher#macos): it also preinstalls the core, sets up the TUN core copy and clears quarantine.
